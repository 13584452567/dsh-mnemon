# ADB/HDC 远端连接修复与真机验证（2026-10-24）

UotanStudio.Comm 的 ADB/HDC 直连（USB 与 TCP）及 server 路由修复，含 Windows x64 真机矩阵结论。实现由 4 个并行子代理分别改动各自文件，随后统一完成构建、format、全量测试与真机验证。

## 关键根因与修复

| 区域 | 根因 / 修复 |
| --- | --- |
| ADB TLS 直连 | `AdbConstants.cs` 的 STLS 版本写为 `1`，会拒绝所有真实设备；改为 AOSP 的 `0x01000000`，`AdbConnection.cs` 按 `>= A_STLS_VERSION_MIN` 接受并回复当前版本。明文收到 A_STLS 时抛新增的 `AdbTlsRequiredException`，不再等满超时 |
| ADB 扫码配对 | `host:pair` 改为 AOSP 的 `host:pair:<password>:<host:port>`；识别 OKAY 后的 `FAIL+4hex+文本` 并保留 server 原始错误；密码含 `:` 时提前拒绝 |
| ADB 读/故障 | `FaultAllStreams` 唤醒握手等待者并快速重抛真实故障；TCP/TLS 传输改为"已到达字节"读取，`AdbConnection` 按无进展期限累计，避免整帧硬断与半帧丢失；TLS 传输释放客户端证书 |
| ADB 发现/配对编排 | `devices-l` 完整串号与 `mdns services` 裸实例名的别名键此前不匹配；配对竞速共用 linked CTS 并在命中后取消输家；`ServerOnly` 禁止直连配对；mdns 按服务类型过滤并按 IPv4/IPv4-mapped 比较地址；`BuildPayload` 拒绝分隔符、控制字符与点号实例名 |
| ADB 身份 | 网络直连改用 `LoadIdentityChain()`，与 USB 路径一致 |
| HDC TCP 直连 | 单次读取 + EOF=0 + 无字节超时；`HdcConnection` 按无进展窗口累计，修复 5 秒空闲自断；声明并发送 `heartbeat`，支持超过 5 秒的首次授权等待 |
| HDC 协议/归属 | 直连 reboot 去掉 `-` 前缀；打开会话改用 `list targets -v`，Offline/Unauthorized 仍归 server；kill 优先 host-channel、pid 回退校验进程；容忍畸形行与含空格 devname；`daemonauthstatus` 按 16 字节 TLV 解析，新增 `HdcAuthorizationException` |
| HDC 端口/宿主 | HDC 裸 IP 拒绝、必须显式 `host:port`；手动 ADB 明文失败收到 A_STLS 时自动重试 TLS 并持久化 `RequiresTls`；手动 HDC 目标新增 `pairedHdcNetworkTargets` 持久化；手动目标与 server 冲突时按 server 归属路由，首次打开前显示 offline |
| 扫码 UI | 手动端口连接传取消令牌；配对目标校验异步化不阻塞 UI，成功后标记 verified |

## 环境事实与操作前提

- HDC 没有 COM/UART 接口，枚举 HDC 目标时不要枚举串口设备；`hdc targets` 中的 COM10/COM11 等 UART 条目不是 HDC USB 目标。
- 之前的 HDC USB 直连失败源于当时该接口未绑定 WINUSB，不是 Comm 代码问题；绑定 WINUSB 后 WinUSB 与 libusb 均通过。
- Comm 采用 fail-closed 路由：HDC server 持有某 USB 目标时不允许直连，验证直连需先停止 HDC server/模拟器（或让 `OHOS_HDC_SERVER_PORT` 指向空端口），结束后恢复 server 与 17035 监听。
- 临时探针放在主机 `%TEMP%`（如 `uotan-hdc-usb-probe`），验证后删除。

## 仍未验证的边界

- Android 11+ 无线调试 TLS：本机只有 Android 9 设备，无真实 TLS 握手证据；STLS 常量与快速失败仅由单元测试覆盖。
- 真实扫码配对：无可控扫码 UI，仅用 `host:pair` 探针确认格式正确；建议用一部手机做端到端验收。
- HDC kill 协议分支：DevEco 会自动重启 server，协议 kill 与 pid 回退未能隔离验证。
- SPAKE2 字节级 parity：仓库无 BoringSSL 测试向量，仅有内部数学/结构验证。
- HDC 发现超时后返回空列表，设备可能短暂从列表消失，未改控制器"复用历史快照"策略。
